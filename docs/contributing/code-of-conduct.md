# Code of Conduct

SoloOps AI adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text at that link applies to all project spaces: repository, issues, pull requests, discussions and any community chat.

## In short

- Be respectful, welcoming and patient, especially with first-time contributors.
- Critique ideas and code, not people.
- No harassment, discrimination or personal attacks, and no publishing others' private information.

## Reporting

> **Action required before public launch:** maintainers must add a private contact (for example a dedicated project email) here. Until then, use GitHub's private reporting to a maintainer.

Reports are handled confidentially. Enforcement follows the Contributor Covenant's community impact guidelines.
